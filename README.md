# 🎬 CinePick AI

**CinePick AI** is a movie recommendation web app that helps you find what to watch based on language, genre, mood, and more — powered by the TMDb API.

## ✨ Features

- 🌐 Language, genre, and mood-based movie picks with colorful native-script cards
- 🎡 "Surprise Me" spin-the-wheel feature (genre-locked, no mismatches)
- ⭐ Community ratings
- 📌 Watchlist
- 🔥 Trending movies
- 📊 Stats
- 🌗 Dark/light theme toggle
- 🔙 Smooth back navigation
- 🔗 Footer with GitHub, LinkedIn, Instagram, and mail links
- 🚫 No login/auth required — jump straight in

## 🛠️ Tech Stack

- HTML, CSS, JavaScript *(single-file architecture)*
- [TMDb API](https://www.themoviedb.org/documentation/api) for movie data

## 🚀 Live Demo

https://cinepickai.netlify.app/

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/muthupriyan-dev/cinepick-ai.git
   ```
2. Add your TMDb API key inside the script.
3. Open `index.html` in your browser — no build step required.

## 🔑 API Key

This project uses a personal [TMDb Developer API key](https://www.themoviedb.org/settings/api) (free tier). Get your own key and add it to the code before running.
